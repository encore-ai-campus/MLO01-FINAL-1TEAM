# 업무톡 UI

저장소 루트에서 기존 API 앱 실행 방식으로 시작합니다.

```sh
pip install -r requirements.txt
uvicorn --app-dir apps rag_api.main:app
```

- `/ui`에서 문서 검색·AI 질문·원문을 이용합니다. 검색·답변·원문 갱신은 htmx가 같은 서버의 HTML 조각을 요청합니다.
- `/ui/demo`에서 직원·관리자 로그인, 가입 신청과 관리 화면을 시연할 수 있습니다. 시연의 상태는 브라우저에서만 관리하며 새로고침하면 초기화됩니다.
- 실제 검색과 원문 열람은 기존 API의 접근 범위를 따릅니다. 실제 AI 답변에는 승인된 사용자 인증이 필요합니다. 운영 로그인과 관리자 기능은 인증·관리 API가 연결되는 시점에 통합합니다.
- 실제 QA 근거 응답에는 출처 등급만 있어 2순위 근거는 외부 자료로 표시합니다. 검색 카드의 공공 양식과 외부 사례 구분에는 API의 `doc_type`을 사용합니다.
- 정적 파일의 htmx는 2.0.11이며 배포 파일과 Zero-Clause BSD 라이선스를 함께 포함합니다.
