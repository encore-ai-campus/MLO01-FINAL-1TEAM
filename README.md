# MLO01-FINAL-1TEAM

## 프로젝트 소개

**AI 기반 사내 문서 검색 및 질의응답 시스템**

본 프로젝트는 사내 문서를 활용하여 사용자의 질문에 관련 정보를 제공하는 AI 기반 질의응답 서비스를 개발하는 것을 목표로 합니다.

RAG(Retrieval-Augmented Generation, 검색 증강 생성) 기술을 활용하여 문서 검색과 LLM(Large Language Model, 대규모 언어 모델) 기반 답변 생성을 구현합니다.

## 주요 개발 영역

- **Frontend:** 웹 사용자 인터페이스 및 화면 구성
- **Backend:** 서비스 API 및 비즈니스 로직
- **AI / RAG:** 문서 검색, 검색 결과 처리 및 답변 생성
- **Infrastructure:** 서버, 네트워크, 컨테이너 및 배포 환경
- **Authentication:** 사용자 인증 및 접근 관리

※ 세부 기능과 기술 구성은 프로젝트 진행 상황에 따라 변경될 수 있습니다.

| 브랜치 | 용도 |
